## Projeto em destaque

### 🔐 [Fredericksen](https://github.com/ThaissaLeslye/fredericksen-api): dados sensíveis com *Security by Design*

Ecossistema familiar para armazenar dados de saúde (alergias, medicamentos, tipo sanguíneo) com criptografia e acesso autenticado.

- **API:** NestJS + TypeScript (strict, zero `any`), Prisma, PostgreSQL. Princípios SOLID, DDD e Clean Architecture
- **Segurança:** AES-256-GCM em campos sensíveis via extensão transparente do Prisma, Google OAuth 2.0 com JWT em cookie `HttpOnly`, container sem root, TLS via Cloudflare Tunnel
- **Qualidade:** testes unitários (Jest), de contrato (Vue ↔ NestJS) e E2E com banco real (Supertest)
- **Infra:** Docker multi-stage, Terraform (WAF e Zero Trust), CI/CD com GitHub Actions
- **Web:** [Vue 3](https://github.com/ThaissaLeslye/fredericksen-web)


### 🧪 [PlataformaQA](https://github.com/ThaissaLeslye/PlataformaQA)
Portal de qualidade full stack em C# (.NET 9) + Angular 21, com backend em camadas, testes automatizados e scripts de banco versionados.
